# Laboratorio 01 — C4

## Objetivo

Modela un sistema real.

## Entregables

Crea:

- System Context.
- Container.
- Deployment.
- Un Dynamic Diagram para un flujo crítico.

Después pasa tus diagramas por el checklist oficial de C4 y corrige ambigüedades.

## Restricción

No crees Component Diagram por obligación. Hazlo solo si el nivel de detalle aporta una historia útil para un lector.
