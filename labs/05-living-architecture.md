# Laboratorio 05 — Arquitectura viva

## Objetivo

Consolidar documentación y mantenimiento.

## Entregables

Crea un `architecture/README.md` con:

- propósito y alcance,
- enlaces a C4,
- escenarios dinámicos,
- deployment,
- índice de ADR,
- atributos de calidad,
- riesgos y deuda técnica,
- glosario mínimo.

Simula una pull request donde una decisión arquitectónica cambie y actualiza tanto el ADR como los diagramas afectados.
