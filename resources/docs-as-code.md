## Flujo sugerido

La documentación vive en el repositorio, cambia mediante pull request, se revisa junto con el código y puede renderizarse automáticamente.

Una arquitectura “viva” no significa documentarlo todo; significa que los artefactos esenciales se mantienen alineados con el sistema.
